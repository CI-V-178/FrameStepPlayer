# ファイル選択

- Google Pickerは詳細リスト（DocsViewMode.LIST）で開きます。サムネイルを取得する権限やフィールドは追加しません。
- アプリ内の選択確認画面は、ファイル名・長さ・作成日時の3項目だけを表示します。画像・プレビュー動画・canvasによるサムネイル生成はありません。
- Driveの長さと作成日時はDrive APIのvideoMediaMetadata.durationMillisとcreatedTimeから取得します。長さが提供されない場合はMP4のヘッダーから読み取ります。
- 端末の長さはmp4boxでヘッダーを読み取って求めます。動画の再生やフレームの画像化は行いません。
- OS標準の端末ファイル選択画面のサムネイル・列構成は、Webアプリから変更できません。OS側の一覧表示設定を利用してください。
- 端末ファイルの作成日時はFile APIから取得できないため、「取得不可」と表示します。lastModified（更新日時）を作成日時として使用しません。
- Google Picker自体の列構成はGoogleが管理します。指定した3項目は、その後のアプリ内確認画面で表示します。
