2. 取得・利用する情報

Googleアカウントの認証情報：Google Identity Servicesからアクセストークンを取得します。トークンはページとService Workerのメモリにのみ保持し、CookieやlocalStorageなどに永続保存せず、運営者のサーバーには送信しません。ページを閉じるとページ側のメモリは失われ、Service Worker側のメモリもWorkerの終了時に失われます。

Google ドライブのファイル：要求する権限はhttps://www.googleapis.com/auth/drive.file（Google ドライブの「このアプリで使用する特定のファイルのみ」）だけです。利用者が選びアクセスを許可した動画、その動画に対応するアプリのメモファイル（.memo.vtt）、アプリが作成した「FrameStep メモ」フォルダを扱います。選択画面ではファイル名・長さ・作成日時などのメタデータを利用します。

動画は利用者のブラウザがGoogle ドライブ APIへ直接リクエストして読み込みます。再生用にメモリ上のBlobを作る場合がありますが、運営者のサーバーへアップロードせず、動画やメモをService Workerのキャッシュに保存しません。端末から選んだ動画もブラウザ内で読み込み、アップロードしません。

メモ：Google ドライブから開いた動画のメモは利用者自身のGoogle ドライブへ保存します。端末から開いた動画のメモは、そのブラウザのlocalStorageにファイル名とサイズをキーとして保存します。VTTの書き出し・読み込みも利用者の操作で行います。

アプリのキャッシュ：Service Workerは同じサイトの/assets/配下にあるJavaScript・CSSなど、画面を構成するファイルをキャッシュします。動画、メモ、アクセストークンはキャッシュしません。

Limited Use：FrameStep Player's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

FrameStep PlayerによるGoogle APIから受け取った情報の利用と他のアプリへの転送は、Limited Use（限定的な利用）の要件を含むGoogle API Services User Data Policyに従います。

3. 取得・利用するGoogleユーザーデータの種類

データ内容使う目的
OAuth アクセストークンGoogle Identity Services で取得Google ドライブ API の呼び出し
選んだ動画のメタデータファイル ID、名前、サイズ、MIME タイプ、親フォルダの ID、作成日時、動画の長さ表示、fps の判定、メモファイルの保存先の決定
選んだ動画の中身動画データブラウザでの再生、fps の判定

取得しないもの：メールアドレス、氏名、プロフィール写真、連絡先、利用者が選んでいない動画やそのほかのファイルは取得しません。

4. 保存場所と保存期間

  • アクセストークン：ブラウザのメモリ（ページとService Worker）にのみ保持します。タブを閉じると消え（Service Worker側はWorkerの終了時に消えます）、最長でもGoogleが定める有効期限までしか使えません。
  • 動画：保存しません。再生中にブラウザが一時的に読み込むだけです。
  • メモ：利用者自身のGoogle ドライブ（利用者が削除するまで）、または端末のブラウザのlocalStorage（サイトデータを削除するまで）に保存します。
  • 運営者のサーバーには、Googleユーザーデータを一切保存しません。

5. データの保護

  • 通信はすべてHTTPSで暗号化します。
  • アクセストークンをCookieやlocalStorageに保存しません。
  • 運営者を含め、人が利用者のGoogleユーザーデータを閲覧することはありません。

6. 利用目的

取得した情報は、動画の再生、フレーム確認、ファイルの選択、メモの保存・読み込みのためだけに利用します。広告、アクセス解析、AIの学習、その他の目的には利用しません。

7. 第三者への提供・移転

運営者がGoogleユーザーデータ、動画、メモを第三者に販売・提供・移転することはありません。Googleユーザーデータを広告、信用力の判定、AI・機械学習モデルの学習に使うことはありません。利用者の指示によるGoogle ドライブへの保存と、次項の外部サービスへの通常の通信は行われます。

8. 外部サービス

  • Google：ログイン、Google Picker、Google ドライブ APIを利用します。Googleのプライバシーポリシーをご確認ください。
  • Google Fonts：アプリの画面でNoto Sans JP、JetBrains Mono、Robotoを読み込むため、閲覧時にIPアドレスやリクエスト情報などがGoogleに送信されます。Google Fontsのプライバシー情報をご確認ください。
  • Vercel：サイトのホスティングに利用します。IPアドレス、ブラウザ情報、アクセス先などがVercelのアクセスログに記録される場合があります。Vercelのプライバシー通知をご確認ください。
  • 運営者はアクセス解析、広告、Cookieによる追跡を実装していません。メモ保存にはCookieではなくlocalStorageを使用します。Googleのログイン画面など、外部サービスによるCookie等の扱いは各社のポリシーによります。

9. Google API Services User Data Policy

FrameStep Player's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

日本語訳：FrameStep PlayerがGoogle APIから受け取った情報を利用し、他のアプリへ転送する場合は、Limited Use（限定的な利用）の要件を含むGoogle API Services User Data Policyに従います。

10. データの削除とアクセスの取り消し

  • Google ドライブのメモ：Google ドライブ上の該当する.memo.vttファイルを削除してください。画面内の×では個々のメモを削除できます。
  • 端末のメモ：ブラウザのこのサイトのサイトデータを削除してください。
  • アクセスの取り消し：Googleアカウントのアクセス許可でFrameStep Playerへのアクセスを取り消してください。取り消しても既存のメモファイルは自動削除されません。
  • 削除の依頼：運営者はGoogleユーザーデータを保持していないため、削除の対象となるデータはありません。ご質問は1.の連絡先へお寄せください。

1. Information we access and use

Google authorization: The app obtains an access token through Google Identity Services. It is held only in page and Service Worker memory, never persisted in cookies or localStorage, and is not sent to the operator's server. Page memory is lost when the page closes; Worker memory is lost when that Worker terminates.

Google Drive files: The only requested scope is https://www.googleapis.com/auth/drive.file (Google Drive access limited to the specific files you use with this app). The app handles videos selected and authorized by the user, associated app-created .memo.vtt files and the app-created “FrameStep メモ” folder. Selection uses metadata such as filename, duration and creation time.

Your browser requests videos directly from the Google Drive API. A temporary in-memory Blob may be used for playback. Videos are not uploaded to the operator's server or saved in the Service Worker cache. Device videos are read within the browser without uploading.

Notes: For videos opened through Google Drive, notes are stored in your own Google Drive. For videos opened through the device chooser, notes are stored in that browser's localStorage, keyed by filename and size. VTT export and import are initiated by you.

App cache: The Service Worker caches same-origin files under /assets/, such as JavaScript and CSS. It does not cache videos, notes or tokens.

Limited Use: FrameStep Player's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

3. Storage location and retention

  • Access token: kept only in browser memory (page and Service Worker). It is discarded when you close the tab (Service Worker memory when that Worker terminates) and is usable at most until the expiry set by Google.
  • Videos: not stored. The browser loads them temporarily during playback.
  • Notes: stored in your own Google Drive (until you delete them) or in this browser's localStorage (until you clear site data).
  • No Google user data is stored on the operator's servers.

4. Data protection

  • All communication is encrypted with HTTPS.
  • Access tokens are never stored in cookies or localStorage.
  • No person, including the operator, views your Google user data.

5. Purpose, sharing and transfer

Information is used only for video playback, frame review, file selection, and saving or loading notes. It is not used for advertising, analytics or other purposes. The operator does not sell, disclose or transfer your Google user data, videos or notes to third parties, and does not use Google user data for advertising, creditworthiness determination, or training AI / machine learning models. Your requested Google Drive storage and ordinary external-service requests described below still occur.

6. External services

  • Google provides sign-in, Picker and the Google Drive API. See Google's Privacy Policy.
  • Google Fonts supplies Noto Sans JP, JetBrains Mono and Roboto to the app. Your IP address and request information are sent to Google when fonts load. See Google Fonts privacy information.
  • Vercel hosts the site and may record IP addresses, browser information and requested paths in access logs. See Vercel's Privacy Notice.
  • The operator implements no analytics, advertising or cookie tracking. Notes use localStorage rather than cookies. Cookies on external services such as Google's sign-in screens are governed by those services' policies.

7. Google API Services User Data Policy

FrameStep Player's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

8. Deletion and revocation

  • Delete the relevant .memo.vtt file in your Google Drive to remove notes saved there. The × button removes individual notes.
  • Delete this site's browser data to remove device notes.
  • Revoke FrameStep Player at Google Account permissions. Revocation does not automatically delete existing note files.
  • Deletion requests: the operator does not retain any Google user data, so there is no data for us to delete. Please send any questions to the contact above.
